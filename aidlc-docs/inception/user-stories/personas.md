# Personas

## P1: 영상 제작자 (Creator)

- **역할**: 이 도구의 유일한 사용자 유형. Cognito 계정으로 로그인해 자신의 영상을 가공한다.
- **특성**: 웨비나·강연 등 긴 원본 영상을 보유. 같은 원본에서 쇼츠와 화자별 편집본을 모두 뽑고 싶어 한다. AWS 내부 구조(파이프라인, S3 키)는 모른다.
- **동기**:
  - 영상을 한 번만 업로드하고 여러 용도로 재사용하고 싶다 (수십 분짜리 업로드를 목적마다 반복하는 것이 가장 큰 불만)
  - 메뉴 이름과 실제 동작이 일치하기를 기대한다 ("업로드" 메뉴에서는 업로드가 되어야 함)
- **좌절 지점 (현재)**:
  - `/upload`에 들어가도 실제 업로드가 안 되고 다른 화면으로 이동만 됨
  - 쇼츠만들기/화자별 편집에 들어가면 매번 새 업로드를 요구받음 — 이미 올린 영상 재사용 불가
- **성공 기준**: 업로드 1회 → 쇼츠·화자별 각각 몇 번의 클릭으로 처리 시작

## 페르소나 ↔ 스토리 매핑
모든 스토리(US-1 ~ US-8)는 P1 단일 페르소나에 귀속된다. 매핑 표는 stories.md 하단 추적표 참조.
